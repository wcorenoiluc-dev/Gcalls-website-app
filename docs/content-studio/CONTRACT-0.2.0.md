# Gcalls Content Studio 0.2.0 — integration contract

Binding for three workstreams built in parallel (React adapter + manifest,
PHP plugin, admin UI). Anything not written here is the implementer's call,
but every name and shape below is fixed. Do NOT commit — the integrator commits.

Baseline: React Shell 0.3.6 live. React Shell becomes 0.3.7 ONLY because it
must ship the generated `content-manifest.json` and expose it through the PHP
contract (reason recorded for the owner before production deploy).

---------------------------------------------------------------------------
## 1. Content manifest (generated by the React build)

File (tracked in git, same pattern as routes.json):
`wordpress/wp-content/plugins/gcalls-react-shell/content-manifest.json`

Generated by `node wordpress/scripts/generate-content-manifest.mjs`
(`npm run content:manifest`), which bundles `src/content/manifest.ts` with
esbuild, executes it, and writes JSON. `npm run build:wordpress` runs it
before `vite build`. Generation is deterministic (stable key order, no
timestamps, no git hashes) so build A = build B.

```jsonc
{
  "manifestVersion": 2,          // bump when this document's shape changes
  "schemaVersion": 2,            // content record schema; PHP stores it per record
  "blockedMedia": ["gcalls-plus-webphone-desktop-v1.webp", "..."], // PII_BLOCKED filenames (shared TS module also used by vite.config.wordpress.ts)
  "pages": [                     // EXACT order and keys of routes.json (38)
    {
      "key": "home",             // routes.json key == CPT post_name == REST {route}
      "path": "/",
      "label": "Trang chủ",
      "order": 0,
      "status": "editable",      // "editable" (pages 01–05) | "review" (06–38)
      "statusLabel": "Có thể chỉnh sửa" | "Đang kiểm tra giao diện",
      "sections": [
        {
          "key": "hero",         // stable, kebab/camel, unique per page
          "label": "Hero",
          "order": 0,
          "previewSelector": "section[aria-labelledby=\"home-hero-heading\"]",
          "fields": { /* name -> Field */ },
          "defaults": { /* name -> value, MUST validate against fields */ }
        }
      ]
    }
  ]
}
```

`Field`:
```jsonc
{ "type": "text" | "textarea" | "richtext" | "url" | "ctaLabel" | "select" |
          "toggle" | "image" | "imageAlt" | "decorative" | "checklist" |
          "repeater" | "cards" | "testimonials",
  "label": "Human label (vi)",
  "help": "optional",
  "required": false,
  "maxLen": 160,            // text/textarea/richtext/ctaLabel/imageAlt/url
  "maxItems": 8,            // checklist/repeater/cards/testimonials
  "options": [{"value":"a","label":"A"}],   // select only
  "item": { /* name -> Field */ }            // repeater/cards/testimonials: item schema (no nested repeaters)
}
```
Value shapes: text-like → string; url → string (http/https or site-relative
`/path/`, `#hash`, `tel:`, `mailto:`); select → one of options[].value; toggle
→ boolean; image → `{id:number,url:string,width:number,height:number,filename:string}` or
null; imageAlt/decorative are plain text/toggle fields that sit beside an
image field; checklist → string[]; repeater/cards/testimonials → object[]
validated item-by-item against `item`. Unknown keys are dropped everywhere.

React infers field types from defaults (`string` → text, ≥120 chars → textarea,
keys matching /url|href|path$/i → url, /label$/i → ctaLabel, boolean → toggle,
string[] → checklist, object[] → repeater, `{id,url,width,height}` → image) and
`src/content/sections/*.ts` may override per field (e.g. richtext, select,
cards, testimonials, help text). PHP never re-declares a schema: it validates
by reading the manifest.

Preview selectors: prefer existing `section[aria-labelledby="<id>"]`; hero
sections use `main > section:first-of-type`.

## 3. Runtime config (`window.__GCALLS_SHELL_CONFIG__.gcallsContent`)

Injected by Content Studio via the `gcalls_react_shell_config` filter for the
CURRENT ROUTE ONLY (never all 38):
```ts
interface GcallsContentBootstrap {
  restUrl: string
  nonce: string | null            // wp_rest nonce in preview only
  schemaVersion: 2
  version: number                 // record version (optimistic lock), 0 if no record
  publishedContent: { sections: Record<string, Record<string, unknown>> } // published (public) or draft (preview)
  seo?: { title?, description?, canonical?, ogTitle?, ogDescription?, ogImage?: {id,url} | null, noindex?: boolean }
  previewMode: boolean
  previewSection?: string
  previewRevision?: number
}
```
Adapter: `useGcallsContent(route, sectionKey, defaultContent)` — merge by
schema shape (defaults ⟵ published ⟵ live preview override, preview only in
`previewMode`). Missing/invalid bootstrap ⇒ defaults. Nothing may throw.

## 5. REST (`/wp-json/gcalls/v1`) — every write: logged in + `X-WP-Nonce` (wp_rest) + capability + route/section allowlist from the manifest + schema sanitize

| Method | Path | Cap | Body / Query | 200 | Errors |
|---|---|---|---|---|---|
| GET | /manifest | edit | – | manifest JSON | 401/403 |
| GET | /content | edit | – | `[{route,path,label,status,hasDraft,version,updatedAt,updatedBy,publishedAt,publishedBy,publishedRevision}]` | |
| GET | /content/{route} | public | `?context=edit` (edit cap) | `{route,schemaVersion,version,sections}` + `draft,meta,seo` in edit context | 404 unknown route |
| POST | /content/{route}/draft | edit | `{section,fields,baseVersion}` | `{saved:true,meta}` | 400 unknown section, 409 `gcalls_cs_conflict` (+meta), 422 `{errors:[...]}` |
| POST | /content/{route}/publish | publish | `{baseVersion}` | `{published:true,meta,publicUrl}` | 409, 422 (schema/URL/alt errors) |
| POST | /content/{route}/discard-draft | edit | – | `{discarded:true,meta}` | |
| POST | /content/{route}/restore-defaults | publish | `{section}` | `{restored:true,meta}` | |
| GET | /content/{route}/revisions | edit | – | `[{id,date,author,isPublished,summary}]` | |
| GET | /content/{route}/revisions/{id} | edit | – | `{id,date,author,sections}` | 404 |
| POST | /content/{route}/restore/{id} | publish | `{baseVersion}` | `{restored:true,meta}` | 400/409 |
| GET | /content/{route}/seo | edit | – | seo object + `{managedBy:'rank-math'|'content-studio', canEditNoindex}` | |
| POST | /content/{route}/seo | edit (noindex: manage) | seo object | `{saved:true}` | 403 noindex w/o manage, 422 |
| GET | /media/check | edit | `?ids=1,2,3` | `[{id,ok,blocked,filename,alt,url,width,height}]` | |
| GET | /audit | edit | `?route=&limit=` | `[{time,user,route,section,action,revision}]` | |

`meta` = `{version,status:'published'|'draft'|'unsaved',hasDraft,updatedAt,updatedBy,publishedAt,publishedBy,publishedRevision,schemaVersion}`.
Optimistic lock: every write carries `baseVersion` (from last GET/meta); the
server increments `version` on each successful write and returns 409 when the
client's `baseVersion` ≠ stored version.
Publish creates a WordPress revision first (native `revisions` support), then
appends an audit entry, then purges cache for that route's URL only.

## 6. Storage

CPT `gcalls_content` (one post per route key; `post_name` = route key;
`post_content` = published JSON `{sections:{}}`; `supports: revisions`).
Meta: `_gcalls_draft_json`, `_gcalls_schema_version`, `_gcalls_version` (int),
`_gcalls_published_revision`, `_gcalls_updated_by`, `_gcalls_updated_at`,
`_gcalls_published_by`, `_gcalls_published_at`, `_gcalls_seo_json` (fallback
when Rank Math is inactive). Audit log: CPT `gcalls_cs_audit` (non-public,
`post_content` JSON per entry). Nothing public, no rewrite, no frontend URL.
No global option holding all pages.

Capabilities: `edit_gcalls_content`, `publish_gcalls_content`,
`manage_gcalls_content`. Administrator: all three. Editor: edit only (pilot).
Others: none. Settings screen requires `manage_gcalls_content`.

Rank Math: when `class_exists('RankMath')`, the SEO tab reads/writes the
WordPress page that owns the route path (`get_page_by_path`, or the front page
for `/`) via meta `rank_math_title`, `rank_math_description`,
`rank_math_canonical_url`, `rank_math_facebook_title`,
`rank_math_facebook_description`, `rank_math_facebook_image` (+`_id`),
`rank_math_robots` (noindex). Otherwise `_gcalls_seo_json` on the content
record and the values are injected in `gcallsContent.seo` for React's Seo
component.

Cache purge on publish/restore (route URL only): `clean_post_cache`,
`do_action('litespeed_purge_url', $url)`, `wp_cache_post_change` (WP Super
Cache) / `w3tc_flush_url` when those functions exist, and
`do_action('gcalls_content_published', $route, $url)`.

Preview endpoint: `{home}/?gcalls_content_preview=1&route=<key>&section=<key>&_wpnonce=<nonce>[&revision=<id>]`
— auth + cap + nonce; `nocache_headers()` + `X-Robots-Tag: noindex, nofollow`;
renders through `gcalls_react_shell_render_root()` (React Shell dequeues theme
CSS/global styles itself for shell renders). With `revision`, the payload is
that revision's sections (read-only compare); without it, draft ?? published.

## 7. Admin (menu "Gcalls Content Studio": Website · Media Review · Revisions · Settings)

`wp_localize_script('gcalls-cs-admin', 'GcallsContentStudio', {...})`:
```jsonc
{
  "restUrl": "https://site/wp-json/gcalls/v1",
  "wpNonce": "…",
  "homeUrl": "https://site/",
  "publicBaseUrl": "" | "https://…",
  "manifest": { /* §1, only routes+sections+fields+defaults, no blockedMedia needed */ },
  "previewNonces": { "home": "…", "products": "…" },   // per route key
  "canPublish": true, "canManage": true,
  "currentUser": { "id": 1, "name": "…" },
  "viewports": { "desktop": 1440, "tablet": 768, "mobile": 390 },
  "reviewLabel": "Đang kiểm tra giao diện",
  "i18n": { "saveDraft": "Lưu bản nháp", "publish": "Cập nhật website", "revert": "Hoàn tác",
            "confirmPublish": "Nội dung này sẽ được hiển thị ngay trên website.",
            "unsaved": "Bạn có thay đổi chưa lưu.", "viewUpdated": "Xem trang vừa cập nhật" }
}
```
Editor layout: left = 38 pages in manifest order with search + status badge
(editable / review); middle = section list (accordion, in manifest order) →
fields per §1 types (technical keys never shown as labels; `help` shown);
right = preview iframe with Desktop 1440 / Tablet 768 / Mobile 390,
Refresh Preview, Open Preview in New Tab, focus-on-section. Per page a "SEO"
tab. Status chip: Draft / Published / Unsaved. `beforeunload` guard when
unsaved. Actions exactly: "Lưu bản nháp", "Cập nhật website" (confirm modal
with the §7 sentence, then publish, then show "Xem trang vừa cập nhật" link),
"Hoàn tác" (revision list → preview revision in the iframe → confirm →
restore). Review pages render fields read-only with the review label.

Media: `wp.media` picker (image only), shows thumbnail/filename/size/alt,
requires alt unless decorative, calls `/media/check` to refuse blocked
assets, "Remove from section" never deletes the attachment.
